루핏 계정 삭제 요청

루핏 계정과 서버에 보관된 데이터를 언제든지 삭제할 수 있습니다.

앱을 사용할 수 있는 경우

  1. 루핏의 설정 탭을 엽니다.
  2. 회원 탈퇴를 누르고 안내를 확인합니다.
  3. 가입한 카카오 또는 Apple 계정으로 재인증합니다.

요청이 접수되면 새 로그인과 기록 업로드를 즉시 차단하고 삭제 작업을 시작합니다.

앱을 사용할 수 없는 경우

아래 이메일로 제목을 [루핏 계정 삭제 요청]으로 보내 주세요.

가입한 로그인 제공자(카카오 또는 Apple)와 회신받을 이메일을 적어 주세요. 비밀번호나 로그인 토큰은 보내지 마세요.

이메일로 삭제 요청

본인 확인에 필요한 최소한의 추가 절차를 안내합니다. 확인이 끝나면 삭제 요청을 접수하고 합리적으로 필요한 기간 안에 처리합니다.

삭제되는 데이터

  • 루핏 내부 계정과 인증 세션
  • 서버에 백업된 완료·취소 운동 기록과 삭제 이력
  • 랭킹 데이터
  • 루핏과 카카오 또는 Apple 계정의 연결

기기에 남는 데이터

현재 기기의 운동 기록과 루틴은 회원 탈퇴만으로 삭제되지 않습니다. 로컬 데이터도 모두 삭제하려면 앱을 삭제해 주세요.
