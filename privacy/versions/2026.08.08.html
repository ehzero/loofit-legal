루핏 개인정보 처리방침

피지크허브(이하 “운영자”)는 루핏(이하 “서비스”) 이용자의 개인정보를 보호하고 관련 고충을 처리하기 위해 다음과 같이 개인정보 처리방침을 수립·공개합니다.

주요 개인정보 처리 표시

  • 로그인은 선택 사항이며 로그인하지 않아도 로컬 운동 기록 기능을 이용할 수 있습니다.
  • 로그인하면 완료·취소 운동 기록이 서버에 백업되고 완료 기록에서 주간 랭킹이 산출됩니다.
  • 다른 회원에게는 매주 바뀌는 임시 표시명과 주간 집계값만 표시됩니다.
  • 소셜 계정의 이름·이메일·전화번호·비밀번호는 운영자 서버에 저장하지 않습니다.
  • 회원 탈퇴 시 서버 계정·백업·랭킹·소셜 연결을 삭제하며 기기의 로컬 기록은 유지됩니다.

제1조 개인정보의 처리 목적·항목·근거 및 보유기간

운영자는 서비스 제공에 필요한 최소한의 개인정보를 다음과 같이 처리합니다. 서비스 이용계약의 체결·이행에 필요한 정보는 개인정보 보호법 제15조제1항제4호를 근거로 처리하며, 별도 동의가 필요한 정보가 추가되는 경우 해당 처리 전에 동의를 받습니다.

카카오·Apple 인증 토큰 원문은 본인 확인 과정에서 일시적으로 처리한 뒤 저장하지 않습니다. Access Token과 Refresh Token 원문은 이용자 기기의 보안 저장소에 저장하며, 운영자 서버에는 Refresh Token의 단방향 해시만 저장합니다.

제2조 개인정보의 수집 방법 및 로컬 전용 정보

  • 이용자가 카카오 또는 Apple 로그인을 실행할 때 소셜 제공자로부터 인증 결과를 전달받습니다.
  • 이용자가 운동을 기록·수정·삭제하면 기기 SQLite에 저장되고, 로그인 상태에서는 완료·취소 기록이 서버에 백업됩니다.
  • API 요청 과정에서 최소한의 서비스 이용 기록이 자동 생성됩니다.

현재 루틴, 다음 운동 위치, 진행 중 운동, 테마·위젯 설정은 기기 또는 운영체제의 앱/위젯 저장 영역에서만 처리합니다. 운영자는 광고 식별자, 위치정보, 연락처, 사진, HealthKit·Health Connect 데이터를 현재 수집하지 않습니다.

제3조 서비스 내부 공개 및 민감정보 보호

로그인 회원은 별도 참여 절차 없이 한국시간 기준 주간 랭킹에 참여합니다. 다른 로그인 회원에게는 매주 바뀌는 루핏 XXXX 형식의 임시 표시명, 순위, 운동한 날, 운동 횟수와 랭킹 인정 운동 시간만 표시합니다. 소셜 계정 정보, 내부 사용자 ID, 운동 부위, 정확한 운동 시각, 분할명과 메모는 공개하지 않습니다.

임시 표시명은 다른 회원이 실제 이용자를 직접 식별하기 어렵게 만든 값이지만, 운영자 내부에서는 계정과 연결되는 가명정보입니다. 랭킹 공개를 원하지 않는 이용자는 계정을 만들지 않고 로컬 기능만 이용하거나 회원 탈퇴를 요청할 수 있습니다.

제4조 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 외부 제3자에게 제공하지 않습니다. 제3자 제공이 필요한 기능을 도입하는 경우 제공받는 자, 목적, 항목, 보유기간과 거부 시 불이익을 사전에 알리고 필요한 절차를 거칩니다. 제3조의 서비스 내부 랭킹 표시는 외부 사업자에 대한 개인정보 제공이 아닙니다.

제5조 개인정보 처리업무의 위탁

수탁자위탁 업무처리 위치 및 관리
Amazon Web Services, Inc. API, 서버 연산, 데이터베이스, 암호화, 로그 및 삭제 작업을 위한 클라우드 인프라 제공 대한민국 서울 리전을 기본 저장 위치로 사용하며 위탁계약과 AWS 보안 통제에 따라 관리

운영자는 위탁계약을 통해 개인정보 보호 관련 의무, 목적 외 처리 금지, 기술적·관리적 보호조치와 재위탁 관리 사항을 확인합니다. 수탁자가 변경되면 이 방침을 통해 공개합니다.

제6조 소셜 로그인과 국외 처리

카카오 또는 Apple 로그인은 이용자가 선택하는 외부 인증 서비스입니다. 인증 과정에서 각 제공자가 자신의 개인정보 처리방침에 따라 정보를 처리할 수 있습니다. Apple 로그인 요청은 Apple의 해외 시스템을 경유할 수 있으나, 운영자는 소셜 인증에 필요한 요청·응답 외의 운동 기록이나 랭킹 데이터를 Apple에 제공하지 않습니다. 소셜 로그인을 사용하지 않으면 해당 인증 절차는 시작되지 않습니다.

  • 카카오 개인정보 처리방침
  • Apple 개인정보 처리방침

제7조 개인정보의 파기 절차 및 방법

보유기간이 끝나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자 파일은 복구·재생하기 어렵도록 삭제하고, 계정에 귀속된 DynamoDB 항목은 탈퇴 처리 과정에서 삭제합니다. 재해복구용 시점 복구 사본은 운영 데이터와 분리되어 삭제 반영 후 최대 35일 동안 보관된 뒤 자동 만료됩니다.

  • 개별 운동 기록: 앱의 기록 상세 화면에서 삭제
  • 서버 계정과 계정 귀속 데이터: 앱 설정의 회원 탈퇴 또는 계정 삭제 요청 페이지 이용
  • 기기 전체 로컬 데이터: 운영체제에서 앱 삭제

제8조 정보주체와 법정대리인의 권리 및 행사방법

이용자는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지 및 동의 철회를 요구할 수 있습니다. 앱에서 운동 기록을 조회·수정·삭제하거나 설정에서 회원 탈퇴를 요청할 수 있으며, 앱을 사용할 수 없는 경우 고객지원 이메일로 요청할 수 있습니다. 운영자는 본인 확인 후 관련 법령에서 정한 기간과 방법에 따라 처리하고 결과를 안내합니다.

법정대리인은 필요한 경우 이용자를 대리하여 권리를 행사할 수 있습니다. 운영자는 대리 관계를 확인하기 위한 최소한의 자료를 요청할 수 있습니다.

제9조 만 14세 미만 아동의 개인정보

서비스는 만 14세 미만 아동을 주된 대상으로 하지 않으며 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 아동의 개인정보가 법정대리인 동의 없이 처리된 사실을 알게 된 경우 고객지원으로 알려주시면 확인 후 필요한 조치를 합니다.

제10조 개인정보의 안전성 확보조치

  • 최소 권한 원칙에 따른 AWS 접근 권한 관리
  • 전송 구간 TLS 및 저장 구간 암호화
  • Refresh Token 단방향 해시와 KMS 비대칭 키 기반 Access Token 서명
  • 프로덕션 데이터 삭제 방지, 35일 시점 복구 및 30일 로그 보관
  • 로그에 인증 토큰과 운동 기록 payload를 남기지 않는 정책

제11조 자동 수집 장치 및 추적

운영자는 현재 웹 쿠키, 광고 식별자 또는 외부 분석·광고 SDK를 이용해 이용자를 추적하지 않습니다. API 운영 과정에서 제1조의 서비스 이용 기록만 자동 생성합니다. 향후 쿠키나 추적 기술을 도입하는 경우 목적과 거부 방법을 이 방침에 추가합니다.

제12조 앱 마켓 및 운영체제 사업자의 정보 처리

App Store, Google Play, iOS, Android 등의 사업자는 앱 설치·업데이트와 운영체제 기능 제공 과정에서 각자의 개인정보 처리방침에 따라 정보를 처리할 수 있습니다. 이러한 처리는 운영자의 개인정보 처리와 구분됩니다.
